# Summary
This survey organizes LLM agents around construction, collaboration, and evolution, providing a broad methodology-focused map of the agent field.

# Why It Matters
It is a useful general anchor for the vault because it connects agent profile design, memory, planning, action, collaboration, and evolution in one framework.

# Method / Setup
The paper develops a build-collaborate-evolve taxonomy, surveys agent components and collaboration paradigms, and reviews applications together with security, privacy, and ethics challenges.

# Key Claims
- LLM agents should be analyzed through methodology and architecture, not only by application area.
- Construction, collaboration, and evolution are the key dimensions for organizing agent systems.
- Real-world deployment requires stronger treatment of safety, privacy, and reliability.

# Limitations
- The survey is broad and therefore less detailed on any one subfield.
- Its taxonomy is descriptive rather than experimentally benchmarked.
