# Graph Memory

## Definition

Cross-cutting hub for graph-structured, relational, temporal, and hierarchical memory systems for LLM agents.

## Core Questions

- When is graph structure better than flat retrieval memory?
- How do temporal, hierarchical, and relational links improve long-horizon reasoning?
- What are the tradeoffs between graph expressivity, update cost, and retrieval efficiency?
- Which systems treat memory as a knowledge graph, temporal graph, or graph-backed indexing layer?
