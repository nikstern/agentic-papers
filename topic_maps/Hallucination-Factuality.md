# Hallucination Factuality

## Definition

Papers on hallucination, factuality, verification, and detection methods for large language models, with emphasis on empirical interventions and evaluation.

## Core Questions

- How should hallucination be defined and broken down into useful subtypes?
- Which interventions actually reduce hallucinations in practice?
- How should factuality and hallucination detection be evaluated?
- When do uncertainty, self-verification, retrieval, or external verification help most?
