# Self Improving Agents

## Definition

Cross-cutting hub for papers where agents improve future behavior through reflection, self-correction, experience reuse, or evolving memory rather than relying only on static prompting.

## Core Questions

- How do agents get better from their own trajectories or feedback?
- What kinds of memory support behavioral improvement rather than simple recall?
- When does reflection help, and when does it just add cost?
- Which systems support continual or inherited improvement without model fine-tuning?
