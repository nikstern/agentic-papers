# Memory Evaluation

## Definition

Cross-cutting hub for papers that evaluate memory systems, long-term retention, memory structure, and memory-driven agent behavior.

## Core Questions

- How should memory in LLM agents be evaluated beyond simple retrieval accuracy?
- Which benchmarks measure long-term conversational retention versus reasoning behavior?
- How do memory structures and management policies affect downstream agent performance?
- Which evaluation settings expose failure modes like drift, forgetting, or bad experience reuse?
