# Benchmarks

## Definition

Cross-cutting hub for benchmark papers used to evaluate agents, memory systems, reasoning, and related LLM capabilities.

## Core Questions

- What benchmark should I use for this capability or failure mode?
- Which benchmarks focus on agents versus memory versus reasoning?
- Which benchmarks are likely to be shortcut-prone versus genuinely diagnostic?
